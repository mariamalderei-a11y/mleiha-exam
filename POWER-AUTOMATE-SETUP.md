# ربط اختبار مليحة مع Excel في SharePoint\n\nأنشئي تدفق Power Automate بمشغل **When an HTTP request is received** ثم أضيفي الإجراء **Excel Online (Business) → Add a row into a table**. استخدمي مفاتيح الطلب التالية: `eventType, attemptId, studentName, startedAt, lastSeenAt, submittedAt, status, score, percentage, easyScore, mediumScore, hardScore, exits, awaySeconds, finishReason, events`. بعد حفظ التدفق انسخي HTTP POST URL وضعيه في أول JavaScript داخل index.html مكان `const SUBMIT_ENDPOINT=""`. الموقع يرسل صفاً عند التسليم ويرسل حدثاً عند مغادرة الصفحة.\n
